# Programming — Beginner to Job-Ready (3–6 months)

## Phase 1: Core Mechanics (Weeks 1–4)
Absolute beginners must build mental models before writing code. The sequence matters: variables and types → control flow → functions → basic data structures. Skipping order creates gaps that become bugs.

Daily template: 20 min concept study (read/watch) + 25 min practice problems (write code, not copy-paste).

Week 1–2 focus: Variables, data types, conditionals, loops
- Day 1–3: Variables, strings, numbers, booleans — write 5 small programs that print output
- Day 4–7: if/else chains — write a number guessing game from scratch
- Day 8–10: for and while loops — FizzBuzz, count-down timers, sum calculators
- Day 11–14: Combine all three — build a CLI quiz with 5 questions

Milestone: Solve 15 HackerRank Easy problems without looking at solutions. If you need hints, you haven't consolidated yet — spend one more week.

Week 3–4 focus: Functions and basic data structures
- Day 15–17: Functions — parameters, return values, scope. Refactor your quiz into functions.
- Day 18–21: Arrays — iteration, map/filter/reduce patterns. Build a student grade calculator.
- Day 22–24: Objects/dictionaries — model real things (user profile, shopping cart item).
- Day 25–28: Mini-project: Build a CLI todo app (add, remove, list, mark done).

Milestone: CLI todo app working with all 4 commands. Code is readable without comments.

Common pitfalls: Watching tutorials without writing code (tutorial hell), skipping to OOP before functions are solid, naming variables "x" and "temp" (use descriptive names from day 1).

## Phase 2: Building Real Things (Weeks 5–10)
Skills become real when you build something that solves a problem. Concept study drops to 30%, building rises to 70%.

Week 5–6: Object-oriented or functional patterns
- Refactor todo app using classes (OOP) or pure functions (functional)
- Study one design pattern: Module, Observer, or Factory
- Milestone: Codebase is organized so a stranger could understand the structure in 5 minutes

Week 7–8: APIs and HTTP
- Learn fetch/axios — make 3 real API calls (weather, random quotes, GitHub)
- Build a dashboard that pulls live data from a public API
- Milestone: Working app that fetches, displays, and refreshes external data

Week 9–10: Databases and persistence
- SQLite or PostgreSQL basics: CREATE TABLE, INSERT, SELECT, WHERE, JOIN
- Connect your app to a database — todos now survive restarts
- Milestone: Full CRUD app (Create, Read, Update, Delete) backed by a database

Daily template: 10 min review previous day's code → 50 min building → 10 min refactor/cleanup.

## Phase 3: Portfolio and Job Preparation (Weeks 11–16)
Employers look at GitHub commits and project quality, not certificates. Three strong projects beat ten weak ones.

Week 11–12: Project 1 — full-stack CRUD app
- Choose a domain you care about (recipes, workouts, finances, books)
- User authentication, database persistence, responsive UI
- Deployed live (Render, Railway, or Vercel + PlanetScale)

Week 13–14: Project 2 — API-heavy or real-time
- Real-time chat, live price tracker, collaborative notes
- At least one third-party integration (Stripe, Twilio, SendGrid)

Week 15–16: Portfolio site + job application prep
- GitHub profile: pinned projects, good READMEs, green commit history
- 50 job applications: target roles with "0–2 years" or "junior"
- LeetCode: 3 problems per day — Easy only until solving consistently under 15 min

Milestone: 3 deployed projects with live URLs. Resume reviewed by someone who has hired developers.

## Common Pitfalls Across All Phases
- Tutorial hell: Cap video watching at 30% of session time. 70% must be writing code.
- Skipping fundamentals: Cannot skip Phase 1 even if you already know basic syntax.
- Comparing to others: Focus on personal velocity — measure against yourself last week.
- Not deploying: Local apps don't count for portfolios. Deploy early and update.
- Breadth over depth: 1 language mastered beats 5 languages dabbled.
